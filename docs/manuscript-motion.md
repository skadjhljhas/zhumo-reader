# 光动与水动：修正跳动，分开运动方式

2026-09-06。用户明确反馈上一轮动态是跳动，且两个主题同质。前一轮“帧有变化”的检查不足以判断运动连续性。

## 修正内容

1. 琉璃、潮生的标题形态不再共用一套曲线只换色。`lucent.glsl` 是折射路径上连续行进的光量，路径本身只缓慢变化；`tidal.glsl` 是不同方向的色散行波，由共同波面 Hessian 的聚光关系生成移动、交汇的水纹。两者均使用现有文章结构、种子和季节输入。
2. 原高斯细光峰没有覆盖像素足迹，部分光峰窄于一个 CSS 像素。新 `band` 使用片元导数估计覆盖范围，并在展宽时保留能量，减少细线移动的闪烁；不支持导数时退回按像素宽度滤波。此项解决采样风险，不把它单独宣称为用户所见全部跳动的唯一原因。
3. 确认的相位跳变：标题及氛围组件在静谧模式中直接使用第 8 秒；ReadingAtmosphere 以绝对启动时刻计算动画时间，离开后台后可能一次跳过整段时间。这些固定相位与追赶行为均已取消。
4. `MotionClock` 保留当前相位，静谧、关闭、窗口隐藏后从原处继续；普通慢帧按真实时间推进，不再把每帧截成 50/60 毫秒而改变流速。超过 250 毫秒的失活间隙视为暂停，不一帧追赶。标题、琉璃背景和潮生背景共用此规则。
5. 本机日内相位纳入毫秒，取消整秒取样的阶梯。画布尺寸未变化时不重置绘图缓冲区。浏览器对照页暂停时停止绘制，并尊重系统减少动态偏好。

水面方程的长度、重力和投射距离均为艺术坐标参数，不宣称为真实海水仿真。画面仍只有水的光纹，没有不透明水池或实体边框。全局正文透光保持上一轮的实现。

## 验证与界限

- 十项映射/时钟单元测试通过，覆盖不同刷新节奏、暂停恢复、失活间隙和秒边界。
- 构建及类型检查通过；修改文件定向 ESLint 与 diff 空白检查通过。
- 在活动的 Codex 浏览器页读取 rAF 回调间隔：旧页与新页中位数均约 7 ms，95 分位约 7.4 / 7.3 ms。此数据不能代表最终屏幕呈现帧率，也不能单独排除视觉跳动。
- 用固定输入与逐步推进的时间读取实际 shader 像素，检查连续帧亮度差分是否孤立突增；记录在对照页 `画面/连续帧检查.json`，与主线程回调数据分开。
- 隐藏 Edge 检查两主题真实阅读器：标题及背景静谧后稳定、恢复流动、关闭、标题几何不变、旁注与编辑布局正常。记录在 `画面/阅读器检查.json`。
