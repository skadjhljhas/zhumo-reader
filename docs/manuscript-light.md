# 文稿自己的光：琉璃与潮生

本页记录第一轮映射。最新运动实现、跳动修复与观看入口见 [光动与水动](manuscript-motion.md)。

2026-09-06，主题分支的可观看实现。用户要求：标题右侧图案由文章结构、季节时间与随机性共同生成；光纹进入文字内部与字距、行距，取消正文整块纯色遮挡。此轮只替换琉璃、潮生的固定标题图案。

## 结构进入形态

从现有 ParsedBook 只读提取；不改变 parser、注释契约或编辑保存流程。正文字数沿用阅读器现有统计口径（正文源码字符，包含部分 Markdown 标记），注文使用现有 searchText 的可读文字投影，排除引用标号、重复的数学辅助 DOM。每个 ParsedBook 只测量一次，WeakMap 缓存随书对象回收。引用位置按正文可读字序归一化。

| 输入 | 变换 | 进入画面的方式 |
| --- | --- | --- |
| 正文 + 注文体量 N | L=ln(1+N/512)，V=L/(L+2.6) | 光形横向展开、消隐长度、层数；大书继续变化而不硬截断 |
| 注文比例 R | 注文字符 / 总字符；渲染使用 sqrt(R) | 光束分流幅度与内部展开 |
| 注释密度 | 注数 /（注数 + 2×max(1,正文千字数)） | 有效光层数；新增层渐入，无整数切换跳变 |
| 注释深度 | 按 ln(1+注文长度/80)+1 加权平均，再压缩 | 各层分离、不同层之间的曲率差异 |
| 注释位置 | 前 4 阶复数矩 Ck=Σw·exp(i·2πkp)/Σw | 保留注释集中在文中哪里，牵引弯曲；高阶按 k² 衰减 |
| 注释分布 | 12 段分布的归一化 Shannon 熵 | 展开间隔与流光节律 |
| 互引与复引 | 父注边数 + 额外引用次数的有界比例 | 交汇程度与曲率频率 |
| 段落长短变化 | 变异系数 CV/(1+CV) | 小尺度弯曲与流速 |

这是一种低维视觉投影；不同文章可能拥有相同统计投影，不能用来鉴别文稿身份，也不把注释多寡当成思想质量分数。嵌套环只参与有限统计，没有递归遍历。

## 时间与相遇

`crypto.getRandomValues` 生成四个 32 位随机数，作为每次打开文稿的相遇种子。滚动、切换琉璃/潮生、编辑后重排都保留种子；再打开文章产生新种子。GPU 浮点量化与有限像素意味着不能承诺数学上的绝对不重复。随机量只进入相位、倾角、微小间隔和色散；文量和注释结构仍控制主要形态。

本机时间通过 Date 读取；日内相位使用本机时区。年内相位使用近似太阳黄经，采用 [USNO 的近似计算式](https://aa.usno.navy.mil/faq/sun_approx)。[香港天文台的二十四节气定义](https://www.hko.gov.hk/en/gts/time/24solarterms.htm)以黄经每 15° 划分；本实现使用连续黄经及极弱的 24 阶调制，避免在分界处跳变。该计算用于美学调制，不提供准确交节时刻，也不读取 Windows 日历界面的文字或用户位置。时令仅轻微影响倾角与色散，不显示季节符号。

动态由连续函数推进，没有逐帧重新随机。标题光形不可交互、不进入辅助阅读树，文字仍为可选择 DOM。静谧模式绘制静帧，关闭模式隐藏；系统减少动态偏好同样被尊重；离开视口或后台页时停止标题动画。

## 光穿过字间

潮生去掉 `.section-body` 接近不透明的底色及 reader-column 遮盖，取消着色器依据整个版心混入纯色的逻辑。底层潮光本身保持适合深色正文的亮度，因此无需一张纯色阅读底板。琉璃保留画外来光，重新加入细微的折光亮侧、暗侧与色散。光在 DOM 字形后，字形内部的空隙与字距、行距自然透出底层；不为每行建立矩形遮罩，不模糊文字。
