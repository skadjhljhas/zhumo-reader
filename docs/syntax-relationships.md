# 句法之光 · 关系、范围与读法

本版将第二个模型作为完整的语言分析者来设计。模型可以提交句法、语义和语篇层的关系；应用负责原文对应、候选隔离及光效。没有按参数规模降低分析职责，也没有自动转交更大的模型。

## 使用

在正文或旁注选择一句话或一个段落，进入「句法之光」。配置第二个模型后，可发送选句；需要全文消歧时，在该模型设置里选择「Markdown 全文与选句」。原文、发送范围、接口、模型名都保留在面板中供检查，生成由读者明确触发。

新版内置提示词强调主语与施事的区别、核心依赖、否定与量化辖域、控制、省略、话题与焦点、指称及态度报告。提示词包含短例子，JSON 契约另附一个完整可用例子。用户修改过的提示词保留，可通过「恢复内置提示词」采用新版；仍与旧默认文本完全相同的提示词在使用时自动升级。

默认最大输出为8192 tokens；已经保存的用户输出长度和接口配置不强制改动。能力与参数规模不用于决定界面功能。输出上限与选区上限只是可调配置或软件边界。

## 阅读结果

- 优先展示关系及其简短依据。点击关系，源单位和目标单位共同显影；悬停正文中的成分也可查看其关联。
- 否定与模态的范围通过 scope 表达。焦点关联使用独立的 focus 关系，不把焦点错误地当作否定的句法辖域。
- 有多个受到支持的读法时显示有名称的切换入口，同时提供区分条件；切换只显示当前读法及共享关系，不混合互斥分支。
- 隐含单位显示在成分说明中，不给它伪造字符位置，也不把恢复词插进原文。
- 可展开「查看成分与依据」查阅各单位。模型状态以文字表达，不显示未经校准的百分比。
- 复制和另存结果生成可阅读的 Markdown，包含原句、关系、成分、依据和候选条件，不再把原始 JSON 当作研究正文导出。

## 光效

「折光」使用冷暖色谱的薄层折射；「潮汐」使用较舒展的水面反射；「共鸣」以关系成员共同的显现节律建立联系。琉璃与潮光使用不同的色谱。曲面的形态缓慢变化；没有实体箭头、星点端点或一排彩色实线。

正文使用精确 DOM Range 和独立覆盖层，不包装、替换或移动正文文字。面板内的例句和正文共享光效组件。静谧与减少动态停止运动，关闭光效移除覆盖层；标签、关系和依据仍可读取。进入编辑、选区失效或取消显示时清除覆盖。原生选字优先。

「先看光效示意」内置四组固定例子：否定、控制、焦点候选和省略；明确标示未调用模型。它们供观察组件和交互，不冒充模型输出质量评测。

## 输出契约与兼容

v2 使用 units、relations、readings。显式单位有1—6个逐字锚点，允许不连续、不同层的交叉或重叠；隐含单位的 anchors 为空。关系有类型、方向、单位ID、解释、依据和 supported/possible/unresolved 状态。最多96单位、128关系、4个完整候选读法；这些上限控制显示与资源占用，不意味着要求把复杂语言强行压缩成浅层树。

应用校验原句、逐字引用、出现次数、Unicode 边界、ID、关系引用及候选一致性。原文外的引用不能假装在选句里定位。只要合法表达交叉关系，就不再受旧版三层片段显示限制。没有文字锚点的单位不会被画成幽灵文字。

原v1片段输出仍兼容；它只能提供其已有的成分信息，程序不会替旧输出凭空编出关系。新增配置和请求仍使用原来的独立第二模型、两种API协议与密钥保护机制，不新增真实模型调用或自动重试。

模型分析正确性与输出格式合法性是不同问题。本次按用户要求不做真实模型能力验证；工程检查使用固定数据、本机接口夹具、隔离配置和隐藏窗口。

## 当前范围

已实现上述关系光效、候选切换、隐含单位显示、提示词升级和 Markdown 结果导出。独立分析旁车文件、人工编辑关系图、跨文稿版本自动迁移，以及真正只按前缀证据运行的增量解析回放，仍不在本版实现中。分析不会因为鼠标停得更久而获得更高的证据状态。
