# 天光与字缘反光

当前方向是明亮、通透的阅读空间。正文保持原来的墨色，天光在实际笔画附近产生类似水面反射的亮纹，并向字缝散开。此前以冷暖墨色变化和 CSS 字影表示受光的试稿已撤回。

琉璃的主光源始终位于画外。随机目标的角分布采用正密度混合：

\[
\rho(\theta)=0.18+2.6e^{2.7(\cos(\theta+\pi/4)-1)}+0.62e^{\cos(\theta+\pi/2)-1}.
\]

屏幕坐标向下为正。反累计分布抽样得到的目标点约为右上 58.6%、左上 20.7%、右下 13.6%、左下 7.1%。目标偏向本身不能保证实际停留时长，因此每次迁移前还有随机驻留：右上驻留较长，上方其它位置次之，下方短暂。初始位置也偏向右上。32 组固定种子、每组 8 小时的模拟中，实际轨迹时间约为右上 79.32%、左上 10.63%、右下 7.76%、左下 2.29%。这些是统计证据，不是逐次阅读的固定配额。

相邻目标之间使用五次曲线 `6u⁵−15u⁴+10u³`。端点的一阶、二阶导数均为零，衔接不会硬折；迁移时长随角跨度增加。再叠加带独立种子的多时间尺度平滑扰动、三段低通参数响应。阅读中的路径是分钟尺度的随机游移。恢复窗口后不追赶后台流逝的动画时间。

折射前沿直接使用入射方向的周期旋转，避免将带分支切口的角度缩放后产生翻转。正下方两侧相差极小的光源位置已做 GPU 像素连续性检查，最大颜色通道差约 0.00049。

方向映射到八次超椭圆外轨道，半径扩大至此前约三倍，最接近画面时仍有至少约 1.5 个归一化屏幕单位的余量。实际光线朝向由画外源点和画内照射中心共同决定。系统时间与节气信号、可见阅读时长、阅读进度、文稿体量和注释结构、注号悬停、文字/空白停留习惯、滚动强度和反向行为共同影响角偏移、行进速率、照射中心、孔径和色温。

主场由一束主要柔光和一束更淡的伴光组成，核心、近晕和外晕分别带克制的冷白、暖色和紫色偏移。原来的多条折射前沿与细条纹合并为一层较宽的微光，避免看起来有很多道光束。HDR 增亮由光场能量驱动，底色仍保持浅而明亮。

`glyph-mask.ts` 按正文与旁注的可见区域建立字形透明度蒙版，使用实际字体和 DOM 排版位置。汉字按实际位置逐字绘制以适应两端对齐与标点挤压，英文词保留内部连写，组合字符保持完整。公式、代码和图解不进入普通字形蒙版。嵌套表格与注释视口的裁切范围同样作用于蒙版，隐藏文字不会向外发光。

`reflection.wgsl` 用同一天光源点计算照度，再让平滑移动的焦散亮纹经过笔画。迎光边缘形成亮部，多级 GPU 纹理让近晕和外晕柔和扩散；原笔画被蒙版排除，避免亮光抹掉深色文字。该层不改写原文，不注册新的字色高亮，模型选定的字色继续独立工作。这是二维艺术化反射，而非对真实液体与字体材料的物理求解。

普通滚动只移动已有蒙版与 GPU 坐标；越过预取范围、字体/宽度变化或内容变动才重建。静谧模式冻结光的时间，仍通过按需重绘响应滚动、布局变化及设置面板关闭。SDR 使用 `rgba8unorm`，HDR 使用 `rgba16float`；浮点画布验证不等同于物理 HDR 峰值或显示器实测亮度。

HDR 背景仍由一次原生 GPU pass 输出，8 个新增光源参数跟原有 32 个场参数一起传递；SDR 使用同一光源几何。固定方位校样使用生产着色器，并为截图压缩高光范围，不能用截图评估真实 HDR 峰值。

当前检查覆盖实际驻留分布、远光源边界、连续运动、恢复无跳位与参数响应，以及字形蒙版裁切、中文对齐、原墨色、原文不变、静谧滚动、调字号和切换 SDR。最新日志为 `work/reflection62-live.log`、`work/reflection62-types.log`、`work/reflection62-lint.log`。这些检查确认实现边界，不代替读者对美术效果的评价。

随后补齐静谧模式的旁注显隐、延迟加载图片的尺寸失效，以及 SDR 图形设备丢失后的本层重建。受影响的内容尺寸通过观察器通知蒙版更新；不需要重新开启光的持续动画。相应桌面验证见 `work/reflection63-live.log`。

字体的排版框不能代表所有字形内部位移，例如 OpenType `palt` 可改变字形定位与进宽。蒙版使用独立的 `FontFace` 别名，将正文已有的特性作为字体描述符交给相同的浏览器字形引擎；正文不换字体。对包内字体沿用对应子集与字重，对导入字体使用其本机字节。不存在的平台备用字体不阻止主字体加载。规范背景见 [OpenType palt](https://learn.microsoft.com/en-us/typography/opentype/spec/features_pt#tag-palt) 与 [字体特性描述符](https://www.w3.org/TR/css3-fonts/#font-feature-settings-desc)。

专项夹具 `tests/fixtures/palt-test.ttf` 的简单字形和 GPOS 数据由项目脚本生成，没有借用第三方字体轮廓。测试用原生 DOM 截图比对蒙版像素，开启相同特性后的归一化误差约 0.137，忽略特性时约 1.135（含抗锯齿与截图差异，不表示零误差）。这比只比较文本框位置更直接；图片、字色与源文仍由原阅读器负责。

历史 53 校样与 60 墨色试稿仍保留在本机作比较，不能将其当作最新反射方案。驻留统计见 `work/sky60-residence.json`，性能记录与测试口径见 [显示节奏](hdr-performance.md)。
