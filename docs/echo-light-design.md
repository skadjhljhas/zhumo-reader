# 回声的光：视觉重构说明

2026-09-08，Claude Code 接手回声系统的视觉表现与应用图标。本文先写对约束的理解，再写实际方案、参数映射和边界。回声的存储、地址、返回导航与 LLM 文本着色接口仍由 Codex 负责，本文不改动它们的契约。

## 一、对约束的理解

**文字才是实的。** 阅读器里唯一允许"实"的东西是排版好的文字。现有回声图之所以像仪表盘，不是因为点太少，而是它由符号组成：等大的小圆点、十字、贝塞尔连线、椭圆轨道、空状态的虚线弧。这些都是实体图形，再淡也还是图表。新的回声图不使用任何描边几何：它是一个用片元着色器逐像素求和的连续光场，每一处停留是光在空气或水面上的一次聚焦，没有轮廓，只有强弱、色温、延展和运动。

**以美丽的光淡去，而不是退成空白。** 原文光效此前把光画在字上：琉璃的深色字被改成浅色，对比度下降，用户自然"看不清"。新方案把字形与光分开。字形只做极小的墨色偏移，两套主题都保持原有的明暗关系（琉璃的墨始终是深的，潮光的字始终是亮的）；真正的光画在正文**后面**的一层固定画布上，位于主题背景之上、正文之下。字形永不虚化，也没有任何字形副本。

**海面反光由月光转向日光。** 3 秒之前一切安静。3 秒后光开始从纸面或水面下方浮现，色温从月白慢慢走向日光，15 秒到达最强。离开时不是原地熄灭，而是像混响一样：峰值降低、范围横向铺开、整体顺着阅读方向缓慢滑移，然后消失。这是听觉回声的三个属性（延迟、衰减、空间扩散）在视觉里的对应物。

**两套主题共有机制，表现不同。** 琉璃是光动：有一个画外的发射体，光场里每一处聚焦都朝向它；发射体缓慢摆动，各处依次被照亮，边缘有极细的色散。潮光是水动：每一处停留是一颗星在夜海上的倒影光柱，随长浪摇曳，越靠近地平线越压缩，明亮的星在水面之上留一粒极小的光。琉璃的运动是"光的到达"，潮光的运动是"水面的呼吸"。

**关联应含蓄。** 记录发生的时刻决定那一处光的月/日色温：夜里读到的字在图上偏银蓝，白天读到的偏暖金。看图的人不需要知道这条规则，但一张图上的冷暖分布确实来自真实的阅读时间。系统当前时刻只给整个光场一点环境色偏移，没有钟面，没有仪表。

**随机且连续。** 每次打开文稿的四个随机种子（`useManuscriptLight` 已有）决定相位与发射体初态；同一会话内所有运动都是连续的正弦叠加，参数用指数缓动逼近目标。位置只由记录的地址散列与文稿位置决定，与排版无关，所以重排、改窗口大小都不会让光场抖动。

**不显示时间。** 时间只是内部参数。界面上没有秒数、没有进度、没有"回声"二字或图标弹出。

## 二、三个表面

### 1. 原文光效（`ReadingEcho.vue` 的 `paint`）

- 字色：CSS Highlights 只改颜色与极细阴影，不改字形。
  - 潮光：基础字色 → 月白 `#eef6ff` → 日光 `#ffe9c2`，全程高亮度。
  - 琉璃：基础墨色 → 靛青 `#2a3d78` → 暖褐 `#6b4a2a`，全程深色，另加 0.3px 的紫/青双侧微色散，与琉璃正文 `strong` 的既有语言一致。
- 光层：`<canvas class="reading-echo-light">`，`position: fixed; z-index: 0`，在背景之上、`.studio-frame` 之下。
  - 潮光：词的基线以下是水。若干竖向柔光条（倒影碎光）横向缓慢漂移、亮度以不同相位缓慢起伏，词的周围有一层很宽很淡的光晕。
  - 琉璃：词的后方是一片被画外光聚焦的纸面：中心向白提亮，边缘左上偏紫、右下偏青（色散），一道柔和的折射前沿每几秒横穿一次。
- 余韵：离开后强度按 `exp(-age/τ)` 衰减；范围横向按 `1 + age·0.25` 铺开；整体向下滑移最多 3px。`τ` 随本次会话对该词的重停次数增加（2.6 s → 最多 5 s）。
- 减少动态 / 静谧：不漂移、不起伏，只保留随停留强度出现与衰退的静态光。关闭光影：不绘制。

### 2. 回声栏紧凑星图（`TidalMemoryChart.vue` compact）

WebGL 片元着色器，输入是一张 3×N 的数据纹理（每处三组 vec4）。不画任何 DOM 星点。空状态只有极淡的环境光（琉璃：一缕画外的光扇；潮光：无倒影的夜海），没有虚线轨道。

### 3. 展开回声（同组件非 compact 模式）

同一光场放大绘制。为保留"记录可访问"：每处停留上方叠一个透明的 `button.echo-star`（无视觉），有 aria-label，可聚焦、可点选；悬停或聚焦时着色器把对应那处的光提亮 1.4 倍，选中的提亮 1.7 倍。列表仍是主要的可访问路径。

## 三、参数映射

"已接入"表示本轮代码中已由真实数据驱动；"拟新增"表示只提出、未实现。

| 参数 | 来源 | 已接入 | 在琉璃中 | 在潮光中 |
| --- | --- | --- | --- | --- |
| 文稿位置 `place.position` | 记录 | 是 | 光扇内的角度：阅读顺序从左下扫到右上 | 水面横向位置 |
| 地址散列 | `tidalPlaceKey` | 是 | 沿光束的距离；稳定，不随排版变 | 倒影的远近（纵向起点） |
| 来处正文/旁注 `origin.kind` | 记录 | 是 | 旁注更远离发射体、更柔 | 旁注更靠近地平线、更压缩 |
| 最长停留 `echo.peakMs` | 记录 | 是 | 聚焦沿光束的长度、亮度 | 光柱长度、亮度 |
| 累计停留 `echo.dwellMs` | 记录 | 是 | 光晕宽度 | 倒影主体宽度 |
| 重访 `visits` | 记录 | 是 | 横向宽度、色温更暖、多一层内芯 | 光柱更宽、更暖 |
| 记录时刻 `place.at` 的小时 | 记录 | 是 | 夜偏冷紫、日偏暖金 | 夜偏月白、日偏日光 |
| 记录年龄（距今） | 记录 | 是 | 越老越宽越淡 | 越老越淡、碎光更散 |

| 本次悬停时长 / 强度 | `echoState` | 是 | 原文光效包络；图上一处正在形成的光 | 同左 |

| 滚动方向（有惯性衰减） | `echoState.direction` | 是 | 发射体斜率微偏 | 浪的横向漂移方向 |

| 阅读时长 | `textSeconds + airSeconds` | 是 | 介质开度（对数饱和） | 环境光量（对数饱和） |
| 系统时刻 / 太阳黄经 | `seasonLight` | 是 | 环境冷暖、发射体初始方位微偏 | 环境冷暖 |

| 本次会话同词重停次数 | `ReadingEcho` 会话内计数 | 是（新增） | 余韵更长、色散更强 | 余韵更长、碎光更多 |

## 四、边界

- 未修改 `tidalPlaces.ts`、`tidalMemory.ts`、`tidalArchive.ts`、`textAddress.ts`、`textNavigation.ts`，未修改 `ChaoshengMemory.vue`。记录数组没有新的保存上限；`TidalMemoryChart` 内 Codex 加入的绘制摘要逻辑（紧凑 64 / 展开 160）原样保留，只作为视觉摘要。
- `ReadingEcho.vue` 的 `finish`、Range 精确定位、3 秒阈值、生命周期清理保留；只重写 `paint` 与光层。
- 数据契约无需改动。若将来希望"记录时刻的色温"更准确，可在 `EchoPlaceDetails` 中加入可选 `hour`，目前从 `place.at` 推得即可。
