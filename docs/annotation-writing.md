# 朱墨 2.0 · 注释写作台

读到一句值得展开的话，可以围绕它写作，再回到原句。注释写作台把当前旁注的 Markdown 和排版放在一起，正文、注释、注内注仍保存在同一份文稿中。

## 进入写作

- **修改已有注释**：点击常驻旁注标题旁的笔形按钮「开启编辑，修改这条注释」。进入写作台本身不会改动已有文字。
- **从阅读选句开始**：在正文或旁注中选字，点击选区旁的「开启编辑，写注释」。原句留在写作来处，引用加在所选范围之后。在旁注内这样操作会写一条子注。操作见[选句写注释](reading-selection.md)，附[阅读范例](reading-selection-example.md)。
- **在原句之后写注释**：先点右上角「开启编辑」，在源文中选择一句话或放置光标，再点「写注释」。选中文字保留，引用加在所选范围之后，写作台显示它的来处。
- **从源文或预览进入**：把光标放在注释定义或标记中，点「修改注释」；也可以点排版预览中的「修改注释」。
- **补写缺失的注释**：未定义注释卡片的笔形按钮会开启编辑并建立对应定义。

## 展开一条思路

左侧书写 Markdown，右侧阅读当前排版。多段落、列表、代码和公式都可以继续写入。修改自动同步到文稿草稿；点保存或按 `Ctrl+S`，写回整份 Markdown。

两侧默认按段落同步位置。写到哪里，排版就来到哪里；在排版中滚动，源文视口也会跟随。可以点击上方「位置同步」暂停跟随，暂时对照两个不同的地方。保存后回到阅读，也会返回当前旁注的对应段落。

如果出现值得单独追问的问题，选择文字或把光标放在注释中的位置，点「写一条子注」。上方路径记录当前写作过程，返回和前进保留光标、编辑滚动位置与旁注的阅读位置。右侧排版中的注内标号也可以进入那条注释继续写作。

「回到引用」把源文光标放到来处的标记之后；「回到文稿源文」定位当前定义的正文。右上角「阅读」切回阅读流程，未保存的修改沿用文稿的保存提示。

## 标号与行内注

修改「标号」后点「更新引用」，会一起更新定义、正文引用和注内引用。代码示例与数学表达式中的相似文字保留。名称不能包含空白或方括号；已有标号和重复定义会给出提示。

`^[内容]` 行内注可以直接修改。需要充分展开时，点「转为独立注释」：当前行内注及其内部的行内支线会转换成独立定义，保留原有标号与引用关系。尚未闭合的行内注需要先在源文中补全括号。改变括号而影响注释范围时，程序保留修改并返回源文，便于检查实际结构。

## 撤销、公式与小窗口

写作台和文稿共用一份撤销历史。`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做；更新标号、建立注释和转换行内注各自成为完整操作。保存沿用原编码与未改动的换行，本机草稿沿用窗口独立恢复。

右侧公式可以展开细读。公式编号和标题链接会转到当前草稿的排版位置；在小窗口中，排版占用完整工作区，点击「回到源文」即可继续编辑。

[注释写作协议](ai-annotation-protocol.md)与[三层范例](annotation-example.md)可用于和 AI 合作撰稿。写作台使用相同的标准 Markdown，无需为它增加专用标记，也不要求固定注释类别、篇幅或文风。
