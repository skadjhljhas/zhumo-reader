# 潮生：创作与试读

这一条分支专门制作一个阅读主题，艺术原点是《潮生》：文字拥有稳定的轮廓，留白拥有可进入的深处，停留与回返能够留下轻微而真实的痕迹。

## 已确认的艺术方向

用户于 2026-09-06 再次明确：实体性的视觉元素尽可能少，要空灵的光效。这个约束适用于整个主题。主视觉使用开放的色散光线、散射余辉与潮汐留白；卷页模型、薄页模型和雕塑式装饰退出当前实现。

光线在空白中相遇、交错、渐淡。主视觉不设置闭合的物体轮廓。注页和旁注卡片撤去堆叠纸边，以真实注层对应的色温和柔光呈现深浅。必要的阅读区域、文字、导航及操作保持清楚。

光标经过留白时推动轻微的水纹与余光；波纹继续传播，再逐渐平息。接近文字时，指针收拢，字形边缘出现极细的复色。文字由正常文本排版，保留选择、复制、公式与编辑的原有路径。

在一个词上稍作停留，会出现细微复色与一枚「回声」入口。点击它，才打开这个词在正文和旁注中的原句。字面出现的位置与上下文来自文稿本身，关系由读者继续理解。

沿旁注支线返回时，光的色温也回到对应层次。变化发生在周围的光与颜色，段落位置保持稳定；长注释的返回仍以实际离开时的阅读位置为依据。

回潮在原句下方剩余的空白中绘制透明余辉，已经接入主线统一的文稿版本、文字地址和导航接口，正在完成集成验证。旧实验缓存保留原样。使用方式与边界见 [回潮](chaosheng-memory.md)。

## 历史样机 02

样机 01 / 02 保留为历史产物，包含此前的实体卷页形态。它们不代表本轮空灵方向的视觉验收。本轮先提供源码与「潮生-光效试稿」中的实际运行画面，新的可执行样机待统一接口接入后整理。

1. 关闭先前的潮生窗口，再打开「样机02」中的 ZhuMo-Tide.exe；首次启动默认进入「潮生」。
2. 打开随附的《潮生》阅读范例，试着在“后来”或“自由”上停留。
3. 点击「回声」比较原句，明确点击「从此处阅读」才改变阅读位置。
4. 将正文注标聚焦后按 Shift+Enter，展开就地注页，再沿注内标号进入第二、第三层。
5. 左侧太阳按钮可以切换丰沛、静谧、关闭光影。系统减少动态效果时采用静态材质。

选择文字和明确开启编辑时，使用原生光标。当前源码在图形上下文暂时不可用时保留静态光线与文稿；关闭光影时无需连续绘制。

## 构建与分支

常规源码验证使用 npm run build。独立艺术打包入口 npm run build:chaosheng 已预留新版本 2.0.0-preview.chaosheng.3，输出至「潮生-艺术预览/样机03」；实际打包在集成验证完成后执行。艺术预览的设置目录为 ZhuMo-Chaosheng-preview，常规阅读器构建使用原有默认设置，历史样机保留。

本分支基于 e0beeae 建立，名称为 feat/chaosheng-theme。阅读器主分支继续承担通用功能与修复工作，主题代码可独立合并。

主线任务负责公共核心与整合发行，主题任务负责空灵光效与阅读体验。双方在 outputs/朱墨协作 共享记录。接下来继续雕刻光线的弥散、文字与留白之间的微妙过渡、注释展开时的光感层次，以及长篇阅读中的回返感。
