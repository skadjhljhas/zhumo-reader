## 数据保护原则

不通过删除旧候选目录整理用户文稿。不在失败时用空目录或默认设置掩盖问题。不覆盖冲突副本。损坏的绑定记录在用户明确选定目录前保留原样。自动化验证使用独立临时资料，不读写真实密钥或执行真实文稿的模型请求。

后续每次交付补充具体提交、产物、命令及结果；未检验的项目继续保持未完成。正式发布前应重新逐项审计，而不是沿用本表的文字作为证明。
