# 静默回声与光场 · 候选08

> 2026-09-08：回声星图、原文光效与应用图标已由 Claude Code 重做，当前视觉说明见 [回声的光](echo-light-design.md) 与 [应用图标](icon-design.md)。下文的视觉描述（SVG 星点、连线、词下水纹）是候选08时的状态；行为约定（3 秒、15 秒、余韵、无计时界面）不变。

## 观看

选择琉璃或潮光，保持「光影：丰沛」。在正文中的一个词上停留：第 3 秒后开始显现，第 15 秒达到极限。移开后有渐退余韵，左下角回声星图记住原句的位置。可连续停过几处不同词语，观察星图的疏密、连线和色泽。文字保持原有排版，不新增包裹节点或字形副本。

潮光使用海蓝背景、月白到浅金的词语反光，以及较舒展的水纹。琉璃使用明亮背景上的深蓝紫字色、细微折射和不同的星图色彩。星图位置的基底保持稳定，实际停留与重访改变它的强度和分布。这里只把可测的阅读行为转为视觉，不把悬停误认为理解。

## 改动

- 潮生的界面名称改为潮光，旧偏好和记录继续有效。
- 移除正文附近的回声浮动按钮与边缘点状残影；潮光着色器的高频亮点改为宽而淡的反射光。
- 滚动方向、活动量和折返余量以有界、缓慢衰减的输入影响光束宽度、角度和反射层次；背景画布固定，不跟随滚动位移。
- 正文注号、返回原文、阅读工具与数学区域保持主题光标。编辑、文本选择和模态窗口继续使用相应原生操作方式。
- 化学公式中透明布局占位 X 被继承的文字阴影显现：现已禁止公式继承字影，隐藏透明占位但保留尺寸。真实变量 X 保持可见，公式源文不变。
- 回声记录由共享 ReadingEcho 收集，原文字地址、版本检查和返回导航仍遵循公共契约。

统计保存在本机现有回声记录中，可暂停、清除和撤销；没有新增网络调用。小窗口收起目录时，可从左侧回声入口打开记录。静谧与关闭光影仍保留查看和返回功能。减少动态偏好禁用波纹运动；关闭光影不绘制回声字光。

## 验证口径

验证使用隔离配置、隐藏且不可聚焦的 Electron 离屏实例；没有弹出测试窗口，也没有使用系统剪贴板。真实等待覆盖 3 秒延迟和 15 秒峰值、双主题共享、存储与精确返回、数学 X、光标、滚动输入及减少动态。后台测试不代表真实显示器帧率。
