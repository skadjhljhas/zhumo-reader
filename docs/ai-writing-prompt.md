# 朱墨 ZhuMo · AI 写作提示词（渲染环境说明）

本目录提供一份可直接投喂给 AI 写作工具的「渲染环境说明」提示词。
它**只描述朱墨如何渲染 Markdown，不包含任何写作建议或风格指令**，
因此不会限制 AI 的发挥，只保证 AI 产出的 Markdown 能在朱墨里被正确呈现
（注释侧栏、作者标号、类型徽标、KaTeX 公式等）。

## 如何使用

1. 打开下方「提示词正文」代码块，整段复制。
2. 粘贴进你使用的 AI 写作工具的**系统提示词（system prompt）**，
   或放在一次对话的最开头。
3. 之后正常向 AI 下达你的写作任务即可。AI 读完这段说明后，
   产出的 Markdown 会自然适配朱墨的注释与公式渲染。

补充说明（可选，帮助你理解而非限制 AI）：

- 朱墨的注释主语法是 GFM 脚注：正文 `[^标签]` 呈上标锚点，
  `[^标签]: 内容` 在右侧栏呈卡片。也支持 `[注N]`/`【注N】` 与行内注 `^[内容]`。
- 标签可以是纯数字、`[^前缀:文字]` 或自由文字；冒号前缀若命中内置类型词组
  会显示同字徽标并配色，否则用中性色。
- 该提示词刻意不列举类型词表、不给示例词，避免诱导 AI 往固定词汇上靠。

## 提示词正文

```markdown
# 渲染环境说明（朱墨 ZhuMo）

你交付的 Markdown 文件将由「朱墨」渲染，供读者阅读。以下内容仅描述该渲染器对各类语法的实际处理方式，不构成任何写作建议。

## 版面

三栏界面：左为目录（自动抽取一至三级标题，按一级标题分章）；中为正文（衬线字体，中西文间距与标点挤压自动处理）；右为注释侧栏。

## 注释

主语法为 GFM 脚注：`[^x]` 在正文中呈上标锚点；`[^x]: 内容` 的定义在右侧栏呈卡片，与锚点双向联动。定义支持缩进续行与多段落，位置任意、均被抽离正文。同一标签多处引用聚合为一卡。定义体内的引用形成子注（层级 = 父 + 1，上限 4）。

每条注释有一个「作者标号」，同时印在正文锚点与卡片头部，是读者识别单条注释的短标识：标签为纯数字（`[^1]`、`[注1]`）时显示该数字；标签为 `[^前缀:文字]` 时显示冒号后的文字；自由标签 `[^文字]` 显示该文字；未提供时显示顺序编号。该标号会脱离正文独立呈现，读者常仅凭它决定是否展开注释。冒号前缀若命中渲染器内置的类型词组，卡片上会显示同字类型徽标并决定配色；未命中的自定义词用中性色；无类型词则不显示徽标。

备选写法：`[注N]` / `【注N】` 配 `注N：内容`；行内注 `^[内容]`。

## 边界行为

代码块内的注释标记按字面保护；悬空引用呈灰色缺失卡；未被引用的定义归入折叠分组；成环引用封顶并警告；`[1]`、`[†]` 不识别，按普通文本显示；全角 `＊＊` 不构成加粗；内联 HTML 按纯文本显示；注释卡文本强制直立（斜体语法无倾斜效果）；类型词超过 12 字符或含特殊字符时不显示徽标。

## 公式

`$...$` 行内、`$$...$$` 块级，KaTeX 渲染，注释体内同样生效。

处理 Markdown 中的 KaTeX 公式时，禁止对 `\(`、`\)`、`\[`、`\]` 进行无上下文的全局替换，因为这可能破坏 `aligned`、`array` 等环境中的 `\\[2pt]` 换行间距语法。转换后必须检查 `$`、`$$` 是否成对，确认 `\begin{...}` 与 `\end{...}` 匹配，并重点排查 `\$$`、未闭合数学块及被误改的反斜杠；交付前应验证所有公式均可由 KaTeX 正常渲染。
```
