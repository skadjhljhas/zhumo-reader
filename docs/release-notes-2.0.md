# 朱墨 2.0 发布说明草稿

此文供下一次发布整理使用，不表示 2.0 已经发布。最终下载文件、版本号、摘要和签名状态以发布时核对的产物为准。

## 本轮升级

- 以 Markdown 阅读和编辑为中心，补齐新建文稿、首次保存和未命名草稿恢复；打开与另存共用默认文稿目录。
- 旁注支持嵌套、共享引用、范围定位、透明度与主题分色。选区动作可全局组合，写注与解释在同一浮页呈现。
- AI 解释和文字着色可以分别配置模型、系统提示词与请求体代码。完整着色记录逐条显影；模型独立选择字色与荧光主色，渐变光晕随原文移动。
- 琉璃与潮光具有各自的阅读光场。回声在停留超过三秒后安静显影，记录保存在本机，不再以24条作为存档上限。
- 琉璃提供 SDR/HDR 选择；UI、正文与注释可分别导入字体。
- 琉璃天光拉远并偏向右上，正文附近新增水面反射式的流动字缘光，保持原文字色；静谧模式仍跟随滚动与字体变化。
- 新增白纸黑字的「白纸」主题，省去装饰书首和「全书完」；全部主题的文稿操作集中到左侧。
- PDF 默认尽量保留当前阅读主题，可包含全文和注释，支持纵向/横向与纸面风格。
- 支持常见未加密、流式版式的 EPUB 2/3 阅读，以及目录、插图、书内链接、脚注和 PDF 导出。
- 保留原版朱字图标。

## 使用范围

HDR 的实际输出取决于系统和显示链路；不支持时回到 SDR。PDF 只保留静态外观。EPUB 暂不编辑原容器，不支持 DRM、固定版式与音视频。未知公式保留源文，不承诺将任意错误的 LaTeX 自动改写为作者本意。

AI 请求发往使用者配置的服务，需要使用者自己的 API 密钥。公开程序不含个人模型凭据、导入字体或文稿。文字着色接口的验证使用固定本地响应；这类软件检查不等同于对模型语言学判断的能力评估。

## 安装与资料保留

正式 2.0 使用独立的产品身份、安装位置和系统入口，与旧正式版并存。第一次使用时，只有一套旧阅读资料便整套沿用；存在多套时由读者选择。密钥及其系统加密状态、导入字体、阅读偏好、回声和草稿一起保留，不拆分或自动合并资料。

安装前先保存并退出阅读器。受管更新按程序清单切换版本，原文稿和完整资料恢复点保留；卸载只清理有归属且未改动的程序文件。用户改过的文件、文稿、设置和恢复点不因卸载而删除。安装或卸载意外退出时，保留现场，再运行同一入口继续恢复，不手动删除事务目录。

rc.4 已通过真实 Windows 安装、同版重装、运行中拒绝、两种卸载中断恢复、卸载后重装和跨产品资料读取，实际程序22条阅读流程及833项源码单元检查通过。当前候选未使用发布者证书签名；最终下载与摘要以发布页为准。
