# 光与字形

阅读有一种安静的精确：**文字留在原处。**光可以流过它，不能替它移动。[^reader]

在全局设置中分别导入界面、正文与注释字体，再观察字形变化以后，光是否仍停留在原句上。SDR 用于阅读，HDR 用于展示；实际输出状态见设置面板。[^light]

## 公式的不同写法

参见后面的方程 $\eqref{identity}$。行内公式也接受括号：\(\langle x,y\rangle\)。

\begin{equation}
e^{i\pi}+1=0 \label{identity}
\end{equation}

\[
f(x)=\begin{cases}x & x\geq 0 \\ -x & x<0\end{cases}
\]

$$
\dfrac{1}{1+\cfrac{1}{1+\cfrac{1}{x}}}
$$

```math
\begin{alignedat}{2}
a&=b+c &\qquad d&=e+f\\
x&=y &z&=w
\end{alignedat}
```

化学式：$\ce{SO4^2- + Ba^2+ -> BaSO4 v}$。扩展微分：$\qty(\dv{f}{x})$。

## 源文仍是源文

下面是代码，不应被渲染成公式：

```tex
\begin{align}
x &= y
\end{align}
```

不支持的表达保留原貌：$\notACommand{x}$。这比猜测作者想写什么更诚实。

自动链接：https://www.commonmark.org/ 。普通金额 $5 和 $10 不应成为公式。
