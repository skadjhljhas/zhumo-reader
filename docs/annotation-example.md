# 一扇门的两种开放

一扇门开着，并不意味着每个人都能进入。台阶、语言、预约和对陌生人的目光，都可能在门框之外继续划定门槛。因而，“开放”至少包含两个问题：入口是否存在，以及一个具体的人能否走到入口。[^门槛]

但如果由此断言“开放只是幻象”，我们又把可以改变的差别抹平了。把一个台阶改成坡道，不能消除世界上的全部排斥，却能改变一部分人的实际处境。对局部改变的判断，不必等待一个没有门槛的世界。[^1]

## 谁在解释这扇门

当管理者说“任何人都可以来”，他可能在描述规则；当来访者说“这里不属于我”，她可能在描述一次具体经验。两句话并未自动构成事实上的矛盾，却可以共同暴露规则与经验之间尚未被处理的距离。[^距离]

这段距离不宜只由其中一方命名。让来访者解释自己的犹豫，也让管理者说明规则的条件，才可能找到需要改变的具体环节。这里再次出现同一个判断：检查开放，需要看入口，也需要看通往入口的路。[^门槛]

## 改变之后

门被重新设计以后，讨论也没有结束。原先有效的解释可能过时，新来的读者可能发现我们遗漏的问题。一份可以继续修订的记录，能够保留变化发生过的痕迹，而不要求过去的每一步都预先拥有最后的答案。[^余响:留白]

[^门槛]:
    这里把“开放”拆开，是为了避免用一条规则替代所有人的处境。同样写着“免费”的入口，可能分别伴随一次短暂步行和一次昂贵的跨城出行。规则相同，并未回答实际进入的代价是否相同。

    这也给“开放”的批评设置了要求：应指出具体的门槛及其作用，而不能仅凭“任何条件都是限制”就宣布一切开放均属虚假。否则，概念将失去区分不同处境的能力。[^反面]

[^1]: “局部改变有价值”并不推出“现有安排已经足够”。它只拒绝用尚未完成的整体任务取消已经发生的改善。一项措施既可能值得实施，也可能仍然远远不够；两种判断可以同时成立。

[^距离]:
    “规则允许”与“体验受阻”回答不同的问题。前者讨论什么行为被明文许可，后者讨论一个人在行动过程中实际遇到了什么。区分二者以后，经验依然可以成为检查规则的材料，而不必被降格为纯粹的主观感受。

    反过来，一次经验也未必足以解释全部规则。需要追问的是：经验中可重复出现的阻碍是什么，它由哪个环节产生，又会影响哪些人。这是一条可继续调查的路径，并非已经完成的经验研究。

[^余响:留白]: 记录留下的空白可以有两种含义：一种是没有注意到，一种是注意到了却暂时无法回答。把它们区分出来，后来者才知道应该补充什么。承认一个问题仍在，并不妨碍我们把已经看见的部分写得准确。

[^反面]: 父注提出了一个界限：批评必须能够区别程度与方式。但这个界限会不会反过来要求受阻者证明太多，才允许他们的经验进入讨论？具体化的责任不能全部落在受阻者身上；设计与管理入口的人，也有主动调查其后果的责任。[^检验]

[^检验]: 这里承接的是父注中“谁承担具体化责任”的问题。一个可检验的安排，是把反馈渠道、处理期限和回应理由公开记录，使提出问题的人不必一再从头证明同一件事。它仍然需要进一步检验：记录是否容易提交，回应是否真的改变了安排，以及哪些人仍然没有进入记录。这些条件说明如何继续判断，并不宣称某一现实机构已经如此运作。
