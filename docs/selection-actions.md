# 选区动作：由全局设置决定

在「阅读设置 → 选中文字后」独立勾选写用户注释、自动解释、自动复制，可组成0—3个动作。初始全部关闭，此时仅保留原生选择。设置随当前用户配置保存。

## 写用户注释

启用后，在正文或旁注选中文字并释放鼠标，输入框立即获得焦点。没有「开启编辑，写注释」中间按钮，不切换整个阅读器到源文编辑页。Enter写入并保存，Shift+Enter换行；输入法组合期间的Enter只留给输入法。非空但未保存的内容在当前会话中保留，Escape关闭后选回同一处可继续。

用户写的内容自动使用 `[^用户注释:1]` 等标签，页边显示「用户注释」身份。保存调用原有版本核对与安全写入；如果外部程序已修改文件，拒绝覆盖，输入内容保留。BOM、原有换行和没有修改的原文片段继续保留。首次保存尚无磁盘位置的示范文稿时，桌面端仍需要选择文件位置；已打开的文件Enter直接写回原处。

## 自动解释与复制

自动解释在释放后或键盘选区停止变化约240毫秒后启动，无需再点击、无需输入本次要求。解释方式由阅读模型系统提示词决定。只有启用了该全局选项且存在配置模型时才发送。与注释同时启用时，两者位于同一个浮层；写注释时不会被流式解释抢走输入焦点。

发送所选原文以及它在Markdown源文中的上文、下文，每侧最多100,000字符，选区另附。该限制是字符而非token；保持原始换行并避免切开代理对。远端窗口按约4k字符边界对齐，因此实际上下文可能略少于上限，这让附近选句复用相同的大段请求前缀。上下文放在请求前部，选句与固定任务说明置后。

重复选回同一处时优先使用本机结果缓存，重启后也可命中。缓存键包括精确上下文、选句、模型/接口、系统提示词和输出设置，不包含请求ID、主题或屏幕坐标。结果用应用现有加密机制保存在本机；不把API密钥写入缓存。只缓存完整成功结果，限制条目数与总大小。服务端前缀缓存仍由服务商尽力实现，不能保证每次命中。

自动复制直接复制选段文本，不弹出菜单或成功提示窗。原有Ctrl+C仍可使用。全部关闭时，不出现选区动作浮层。模型连接错误只在已开启的解释区域显示，不弹系统窗口。

## 注释范围如何放进Markdown

普通脚注写法提供引用点，没有自动表达选区起止。本版保留普通脚注，同时加入朱墨的范围扩展：

```markdown
这是一段所选文字。[^用户注释:1]

[^用户注释:1]: 用户写下的注释。

[zhumo-range-唯一ID]: zhumo-range:v1 "经过URI编码的范围数据"
```

范围数据含标签、逐字原文、格式版本与「结束于这条注号」的锚定规则。它使用一个未被引用的链接定义承载，普通Markdown阅读器会忽略这个定义，仍可显示普通脚注。朱墨读取后，悬停或聚焦注号时，在该注号前精确恢复对应的整个选段。起点由原文长度与逐字匹配确定，因此不是把一组会随编辑过期的绝对下标写死。

前方插入文字不必使范围失效；如果被注释原文本身已改动，或标签被手动重命名导致无法对应，则不猜测范围。范围只影响高亮，不改变原文。隐藏的范围定义不计入正文字数。

本版保存的范围是连续选段，最多64k字符；过大或不能准确定位的选区会保留输入并提示缩小或重新定位，不添加错误注号。修改标签、手工编辑扩展数据以及跨工具重排后的智能范围迁移尚未实现。

## 网页与桌面

网页示范文稿中的注释存入当前浏览器预览存储，状态显示「网页暂存」，不冒充磁盘保存。原生文件读写与已配置模型的自动解释在桌面版使用。用户API配置没有放进网页快照。

手动AI工作台仍可从左侧工具栏打开，并接收当前选区；常态选区浮层不再显示「问AI」「句法之光」菜单。句子有效可见10秒后自动语法分析的后台调度仍是后续范围，本版不提前开启它。本轮模型流程检查使用本机固定响应，没有调用真实模型做能力验证。
