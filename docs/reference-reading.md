# 在页边辨认一个声音

注号是正文与旁注之间的小入口。它需要容易找到，也需要在读完之后让出位置。

当前注号使用一组明确的文字和底色。琉璃仍保留透光的小切面，星辰仍保留细微光晕；主题材质不会再覆盖当前标号的文字或底色，造成浅底浅字。

注释深入时，层级由卡片位置、缩进和边线表达。注号本身不再逐层降低透明度，深处的入口也保留完整的字面清晰度。

键盘进入阅读区时，页边细线表示焦点。正文、旁注、展开注页和编辑预览使用相同的方式；按钮与链接仍保留各自的焦点环。选字、复制、沿注内引用进入与返回的操作保持原来的含义。

这些变化不增加悬停操作提醒。快捷键仍写在应用内的示范文稿中，读者可以按自己的节奏查阅。
