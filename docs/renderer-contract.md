# 朱墨 2.0 · 渲染约定

本说明只描述渲染行为，不规定写作风格、注释类别、密度或篇幅。

朱墨默认进入阅读模式。中间是正文，右侧是可独立滚动、固定和跟随的常驻注释，左侧目录抽取 H1–H3。长章节在完整 Markdown 块边界进一步切分，标题之间的引用式链接仍可使用。需要修改文件时由用户明确开启源文编辑。

脚注引用写 `[^标签]`，定义写 `[^标签]: 内容`。标签非空，不包含空白或方括号。定义后续非空行缩进四个半角空格，空行分隔段落。注内引用形成层级关系；子注定义仍独立置于顶层。相同标签的多次引用聚合为同一张卡，每个标签只定义一次。默认显示层级上限为四层，用户可调整至一到六层；内容不会因达到显示上限而被删除。

作者标号按原文保留：数字标签显示原数字，自由标签显示原词语，`[^前缀:标号]` 通常以冒号后的部分作为上标，并显示作者前缀。自定义前缀不必命中固定词表；超过十二个 UTF-16 码元或含不适合徽标显示的字符时，不显示类型徽标。标签本身仍是引用身份。避免用重复标签表示不同章节的不同注释。

也识别 `[注N]`、`【注N】` 配 `注N：内容`，以及行内注 `^[内容]`。`[1]`、`[†]` 是普通文字。代码范围内的类注释写法按原文保护；数学范围内的类似标记不应创建注释。

注释支持多段落、强调、列表、表格、代码、图片、链接和公式。注释文字保持直立；数学斜体仍由公式排版规则决定。缺失引用、重复定义、未引用定义与互引环会形成解析提示。

「注释脉络」展示当前注释的直接联系：正文中的每个引用入口、引用它的父注，以及它继续引用的子注。关系来自文稿里的实际引用；文字相似不会自动生成连线。多次引用同一条子注形成一条注间联系，多处正文入口仍各自保留。节点较多时分页浏览，注释全文保留在独立阅读区。作者无需为这一视图增加额外标记，也无需为了图形密度而增加引用。

「就地注页」可在正文标号附近预读注释，展开后沿注内引用继续阅读，并按路径返回离开的段落。浮页保留可选字、可滚动的完整注释，以及通往常驻旁注和脉络视图的入口。悬停预读可关闭，键盘仍可展开。注释不会为了适应浮页而被缩写，作者无需限制注释长度或增加专用语法。

「注释写作台」在用户明确开启编辑后，显示单条注释的源文与排版，修改回写同一份 Markdown。子注仍采用独立定义，标号更新沿实际引用同步；写作者无需添加额外格式。

全文检索按字面寻找正文与旁注里的各次出现，同段中的重复词也有独立位置。「原文对读」可把明确选定的两处文本并列，分别滚动、展开旁注、查看公式与图解，并回到各自的原文。连接只表示选定的标记位置，不代表软件判定了语义关系；作者无需增加专用标签或为了对读而拆短段落。

支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 与 `math` 代码围栏。KaTeX 处理常见数学表达式，MathJax SVG 补充部分扩展环境。公式可放大并复制 LaTeX。不能排版的表达式保留源文；朱墨不是完整 TeX 编译系统。各文稿的宏定义与公式状态相互隔离。不要对反斜杠与公式定界符进行无上下文的全局替换。

在数学范围内，可用 `equation`、`align` 等环境自动编号，用 `\label{名称}` 标记，并用 `\eqref{名称}` 或 `\ref{名称}` 引用。引用可以先于公式出现，也可以跨越正文与旁注；编号按正文、再按旁注文档序处理。每个公式标签应唯一。阅读与编辑预览中的编号链接可以定位对应公式；公式标签与脚注标签是两套独立身份。

支持标准 Markdown 标题、引用、列表、强调、表格、代码和链接。原始 HTML 按文字显示。本地相对图片路径以 Markdown 所在文件夹为基准；标题片段链接支持中文与重复标题后缀，相邻 `.md`、`.markdown`、`.txt` 链接可在朱墨中打开。远程图片当前不会自动加载。

标为 `mermaid` 的代码围栏可在正文和旁注中呈现图解；注内围栏仍遵守四空格续行缩进。图解保留源文，支持放大、平移、全览定位及复制 SVG，编辑预览采用同一排版方式。流程图和时序图中的公式可用 Mermaid 的 `$$…$$` 标签语法，与正文的宏定义和编号独立。图解不执行交互脚本或加载外部图像，排版错误时显示完整源文与原因。操作和范例见[图解细读说明](diagram-reading.md)。

本地文件支持 UTF-8（可带 BOM），以及带 BOM 的 UTF-16 LE/BE。源文编辑保存时保留原文件编码、BOM 与未修改的换行。新文件默认采用 UTF-8。遇到无法可靠解码的文件，朱墨提示先转存为 UTF-8。
