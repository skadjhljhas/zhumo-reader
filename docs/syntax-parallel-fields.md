# 五秒、并发与多算子光场

本轮修复针对实际反馈：模型输出到中途出现“不完整 JSON 行”、随后不再显影；多句串行等待过长；多个量词/否定被简化成下划线。

## 流式交付

SyntaxStream 按完整 JSON 对象的结构分帧，不再用换行作为唯一交付边界。对象最后一个括号抵达即可校验，支持连写、格式化、围栏与跨数据块转义。能隔离的坏对象只报告本批问题；后续自足、逐字可定位的 patch 仍可继续显影。坏单位不会进入关系图，其他关系不能引用它。无法可靠定界的未闭合对象不猜测修补；到流结束时报告不完整。

读取 drainIssues 通知不清除完整性错误。包含未修复坏批次的整次结果不进入完整缓存；已经显示的有效部分保留。全局容量限制继续生效，不执行模型输出的代码。

## 调度与缓存

前台可见时间门槛默认连续五秒，可在阅读设置中调为 1–15 秒；后台时间不计入。每个阅读窗口最多十个自动句段独立运行，空闲名额补入已满足可见条件的下一句。切换后台或打开面板暂停新请求，不反复丢弃已发出的推理。编辑、关闭自动光效、换文稿或模型配置会精确取消本窗口对应任务。

主进程在读取配置和缓存之前同步预留名额。后台句法不再因另一句开始而被取消；手动句法和阅读解释仍分别保留最新的前景请求。完成的同一配置/上下文/句段复用既有加密缓存；automatic 调度标志不改变缓存键，也不进入服务商消息。并发不等于把全文一次性交给模型。

## 多个算子的呈现

scope/perspective 的主体改为二维径向羽化光场。每个关系保留独立ID、原词及 occurrence、明确的祖先路径、真正从根开始计算且不压成三层的深度。光场用实际原文行片段生成，原文区域降低光层覆盖；文字自身的样式与笔画不变。

原词层级只承认模型实际给出的 within。没有 within 的重叠片段保持平级；不能从几何包围关系推断语义。竞争读法分别投影。留白中的小型原词谱可放在页边、行后或首行前；没有足够空间时明确保留未放置状态，不缩成无法阅读的小字，不压正文。

已被光场表达的 scope 不叠加旧的 envelope 下划线；这些词若同时参与依赖、控制或照应，相关连接仍保留。跨行独立照应使用不重叠的页边通道，连接两端各有局部渐变，避免变成无法追溯端点的一根光柱。通道记住已有分配，流式新增关系不随意移动旧光；走廊只考虑关系实际跨越的行，仍避开这些行内未选中的文字、公式与图片。

内置提示词同步强调多个实际算子的独立身份、不能隔着量词消去两个否定、限制域/核心域/变量绑定的区别，以及不能把逻辑改写伪装成原句的另一读法。旧21–26内置字符串按精确匹配迁移；自定义提示词保留。

## 验证与边界

固定接口测试覆盖十一句阅读、十请求并行且第十一个排队、坏批次后继续显影、空位补充、十个完整结果缓存命中而坏结果重试；四算子同句、灰度、窗口缩窄；以及照应光路不穿过中间文字。它们不调用用户模型，不评价模型能力。

这不是完整形式语义引擎。现有协议没有量词子类、显式绑定变量、限制域/核心域的专用机器字段，相关区别仍需要依据说明。二维光场本身不能代替可读的结构线索；审美强度、密集长文、很深的分叉和无留白时的替代呈现仍需要继续打磨。详细语言学审查见 syntax-operators-design.md，其中标明了拟议协议与当前实现的边界。
