# 让阅读与书写留在同一处

读到文稿中间，点击「开启编辑」，源文与排版会来到当前段落。默认开启「位置同步」：在源文中移动光标、书写或滚动，排版跟随；在排版中滚动，源文视口也会跟随。

同步依据正文段落、代码与公式块、具体旁注的位置。长段落同时保留段内进度。两边的字号与行宽可以不同，不需要有相同的页高。

## 写作中的来回

注释写作台也支持两侧跟随。在一条长注释中读到后面的段落，可以回到对应的源文继续书写。保存修改，再点「阅读」，正文或常驻旁注会来到这一处。

点击公式编号、标题链接或注内引用时，明确的跳转优先执行，自动跟随不会把页面拉回旧位置。

若要暂时对照两个不同的段落，点上方「位置同步」即可暂停自动跟随；再次点击恢复。这项选择会记住。在小窗口中，「显示预览」与「回到源文」也保留对应位置。

位置跟随本身只改变视图，不会写入文稿，也不会把键盘焦点从正在使用的一侧移走。仍需明确开启编辑才能输入，保存沿用原有编码、换行和修改保护。

## 安静地认识操作

注号上的悬停快捷键提醒已移除。Shift+Enter 仍可展开已聚焦注号的完整注页；快捷键及其他操作写在应用内的示范文稿《在世界与思想之间》中。正文的悬停预读保留，读者可以自行决定是否继续展开。

琉璃与星辰的鼠标采用细光迹：移动时轻轻延展，停留时收敛；落在文字上变为细竖线。选字、编辑、对话框和静谧模式继续使用原生鼠标。
