# 琉璃：光里的阅读空间

用户选择以琉璃作为艺术化设计的主体，继续遵守“文字才是实的，其他以美丽的光效淡去”。

这轮从光喻参考中吸收画外光源、统一传播方向、柔和衰减与高光层次，保留琉璃的冷白、浅蓝与细微色散。晶体实体退出画面。光的折射和透过感在空气中发生。

## 当前初稿

- lucent/light.glsl 统一主光束、较宽的散射、薄弱的色散和在光中才可见的微尘；不再对实体宝石进行光线步进。
- 星辰的着色函数保持原有内容；共享的渲染接口不改变。
- lucent-art.css 只处理琉璃的视觉表面：中心阅读区融入整体光场，旁注减少封闭框与实体阴影，弹层保留必要的清晰承托。
- 标题使用稳定的深蓝，取消会削弱字形的强高光覆盖。正文不模糊、不随光移动。
- 琉璃不再在鼠标旁复制飘动的文字片段；真实文字、细光迹和原有指针状态继续保留。
- 浏览器艺术预览用于观察入口、正文、旁注和编辑布局；它不能替代桌面保存能力与完整运行验证。

## 继续打磨的判断

1. 光是否有明确的来处和距离，而不只是浅色背景？
2. 正文与旁注是否属于同一个空间，同时都清楚可读？
3. 阅读时是否能感到光的存在，又不会被它持续夺走注意？
4. 与原琉璃相比，保留了哪些值得保留的清透感，改动是否真正更好？

目前是可操作初稿，不以“彻底艺术作品”作为已完成结论。原版对照保留，后续依据实际观看反馈调整。
