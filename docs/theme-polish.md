# 主题全面打磨：执行与完成审计

目标原文：把主题的各个方面都给好好打磨。几个小时内都是你自己干了。

当前范围为用户逐轮确认的琉璃与潮生。琉璃是清透折光，潮生是明亮、开阔的沧海蓝与银蓝潮光。文字清晰且可选择，光进入字内/字间/行间；实体性装饰尽量少。潮生避免绿色、碎小聚光网与压抑近黑底色。文章结构、时间与每次相遇的随机性继续参与标题光形。

## 完成要求与证据

每项只有经当前源码和对应实际运行证据验证后才勾选。类型检查、帧发生变化和静态截图不能代替运动/阅读体验的证据；背景回调间隔不等于显示呈现帧率。

- [ ] 两种主题的光/水运动有明确性格，丰富而连续，保留已确认色调与无实体的方向；保留同文对照与动态样本。
- [ ] 文章体量、注释比例/层级/位置/互引、段落节奏实际进入形态；包含普通散文、紧凑嵌套列表、表格、公式、图解、空文与长文的统计验证。
- [ ] 统计不会因大文稿阻塞阅读，过期结果不会覆盖新文稿；编辑重排/参数更新的光形平稳衔接；种子稳定和重新相遇均有证据。
- [ ] 充分检查正文、旁注、元信息、引用标号、选区、表格、代码、公式、图解、搜索/对读、设置、主题库、回潮和编辑表面。正文与普通可读文字目标对比度至少 4.5，较大标题至少 3；以实际背景与适用状态测量，不把一个样本外推到整页。
- [ ] 鼠标在文字/空隙/交互控件中的反馈明确、轻盈；选择、复制、键盘焦点与浮层操作正常，光效不夺取输入。
- [ ] 静谧/关闭/减少动态、暂停恢复、后台返回、尺寸变化与 WebGL 丢失/恢复都有稳定行为；无不必要的持续后台绘制。
- [ ] 390/600/820/1140/1500/宽屏的阅读和展开旁注布局经过验证；文字不被压成狭条，浮层完整可用。
- [ ] 视觉层与当前已提交核心契约兼容，已协调公共改动；没有第二套解析/保存/文字定位语义。
- [ ] 相关单元、真实浏览器及必要的后台 Electron 验证完成；错误、跳过与验证边界如实记录。
- [ ] 源码有可回退提交、文档说明一致，最终静态预览/动态演示和独立桌面候选可打开；原现场与旧分发物保留。
