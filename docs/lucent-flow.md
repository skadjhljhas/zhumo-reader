# 琉璃：持续流动的画外之光

本版专注琉璃。画外圣光的来向、光锥开度、透射层次、色散和反射结构都参与缓慢变化。画布固定于视口，文字位置不跟随光移动。细节由连续光场生成，没有逐帧随机换图，也没有漂浮亮点。

## 参数到光的映射

| 输入 | 在琉璃中的作用 |
| --- | --- |
| 本机系统时间、日内时刻 | 光源来向、环境冷暖；跨午夜采用连续的圆周坐标 |
| 太阳黄经与节气附近的细小谐波 | 圣光的偏移和环境色，属于视觉近似，不作为历法显示 |
| 本次文稿可见阅读时长 | 对数饱和地改变介质开度和折射层厚度 |
| 阅读进度 | 轻微改变来向，不按滚动位置平移背景 |
| 文稿体量 | 正文与注释字数取对数，映射到光程衰减与光锥厚度 |
| 注释文字比例 | 细部透射结构和色散强度 |
| 注释层级、密度 | 折射深度、光束内部细纹密度 |
| 注释分布与引用位置的复数矩 | 光束疏密与折射前沿的位置关系 |
| 段落长短变化、交叉引用比例 | 介质纹理和多层透光的相互关系 |
| 悬停正文注号的位置与层级 | 让其所在阅读行附近出现宽而淡的光层变化，缓进慢退 |
| 上下滚动方向、活动量和折返 | 延迟地改变来向、宽度和色散；约数秒平滑，不直接拖动光场 |
| 鼠标在文字/空白的停留比例、字上停留、静止和区域切换 | 反射、细纹与半影层的轻微变化，不据此推断理解程度 |
| 每次打开文稿的四个独立随机种子 | 光源初态、纹理相位和层间关系；阅读与保存期间保持，重新打开才更新 |

以上通过8组vec4进入光场，共32个数值分量。数量不等于32种独立语言学指标：季节、时刻和随机初态等本来就有多个坐标分量。每个分量均有独立的GPU像素影响检查。

## 动态与稳定性

光源使用数个不同速度的连续相位，画外圣光会缓慢改变方向与宽度，内部透光层有自己的运动。折射前沿横跨文字间隙，与圣光一起演化；不以调低正文清晰度制造效果。

先接入候选13的慢帧计时修复，继续推进大于250毫秒的可见帧。参数缓动也按真实慢帧间隔推进，不再仅按0.1秒推进。隐藏页面与暂停通过显式挂起处理，恢复时不追赶长时间的后台相位。

绘制循环先安排下一帧，另有只在丰沛且可见时生效的恢复检查；不因一次中断永久丢失调度。pageshow、模式切换与图形上下文恢复会重新接上循环。静谧/关闭和系统减少动态偏好继续受尊重。

没有WebGL时仍为原有静态降级材质；本版的32分量动态映射针对正常WebGL光场，不把静态降级伪装成同等动态。常规丰沛模式在欢迎页和阅读页均运行。

## 检查口径

检查包括：正常时间的像素变化、注号悬停渐入与余韵、阅读时钟、32控制分量的独立GPU图像变化、固定种子下圣光亮区位置与宽度随时间变化、重开随机初态、WebGL恢复、静谧与关闭、慢帧以及长文正反滚动。

受控时间截图只比较着色器不同时间状态，不冒充真实等待时长。隐藏离屏窗口测试不代表真实显示器帧率；本轮不调用真实AI模型。潮光仅随接入的候选13基线保留计时修复，本轮不重做它的视觉。
