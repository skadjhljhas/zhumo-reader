# 朱墨 2.0 · 注释质量验收

这份表用于检查 AI 产出的实际文章。提示词和解析测试能减少错误，不能代替对文章本身的判断。不要把下列项目变成注释写作的固定配额。

## 内容检查

| 检查对象   | 合格表现                               | 应当返工的表现                         |
| ---------- | -------------------------------------- | -------------------------------------- |
| 正文主线   | 跳过可选旁注，仍能理解论证如何推进     | 关键前提只存在于深层注释               |
| 注释增加   | 能指出新增的区分、理由、材料或思路     | 只是换词复述正文、宣布“意义重大”       |
| 入口与来处 | 锚点具体，注释单独出现仍有语境         | 泛泛段尾标记、无法判断“这个”所指       |
| 思考的发展 | 内容围绕问题展开，长短合乎需要         | 强行压成摘要，或用无关知识延长篇幅     |
| 注内注     | 父注中确实产生了独立支线               | 连续一句话被拆成三层，或每注机械生子注 |
| 多处引用   | 各个入口都需要同一份讨论               | 不同问题为了少写一条注被强行合并       |
| 命名与声音 | 标号、词语和文风服务具体作品           | 所有内容被迫套入固定身份标签           |
| 来源责任   | 引文可查，推论有依据，未知之处诚实呈现 | 杜撰引文、版本、页码或权威归属         |

## 结构检查

全篇标签唯一；每个引用有定义；定义从正文可达；父子关系由实际引用形成；多段落与块级内容缩进正确；没有意外互引环；公式源文没有被脚注扫描改变。阅读模式中检查实际排版，再检查源文是否忠实保存。

## 验证任务

1. 对一段清楚的普通说明补注，允许得出“不需要增加注释”的结果。
2. 对一段包含关键隐含前提的论证补注，分别测试“可改写”与“只允许补注”：前者可重新安排必要信息，后者必须保留正文并在注释中清楚指出缺口，不能越过授权。
3. 写一段具有真实异议的旁注，检查它是否具体说明异议的条件与影响。
4. 让两处正文共用一条注，检查两个入口的语境是否都能被照顾。
5. 在一条注中自然地产生一个支线，检查 AI 是否能解释父子关系，而非机械增加层数。
6. 整理一本各章都从编号 1 开始的书，检查完整标签是否避免重复，以及原有显示编号是否被尊重。
7. 对缺少版本与页码的来源材料补注，检查 AI 是否拒绝补造出处。
8. 在诗、札记或实验文章中使用旁注，检查文风是否被无故改成教科书。
9. 保持原文逐字不变，只添加注释，检查原文和引文的忠实度。
10. 写含多段落、列表、表格和公式的长注，再沿嵌套路径逐条阅读。
11. 并置两处用了同一个词、含义却不同的段落，检查 AI 是否分别辨认语境，而非凭词形相同宣称二者相互支持。
12. 给一段保留人物动机空白的文学文本补注，检查 AI 是否从措辞提出有依据的读法，能否保留不确定性并承认不加注的可能。

可以把同一任务交给不同模型或不同版本的协议，保留原文、实际输出和逐项判断。比较的对象是完成后的作品，而非模型对自己表现的评价。当前随附范例已经经过朱墨结构解析；尚未将这些任务宣称为跨模型实测成绩。
