# 回声：回到停过的那一句

在潮光或琉璃中，将鼠标停在正文或旁注的词语上：前 3 秒不改变字色，之后缓缓显现，在本次连续悬停第 15 秒达到最强。潮光从海面的月白反光转向浅金日光；琉璃保留深色字形，呈现冷蓝到淡紫的折射。移开时余光缓慢消退，左下方「回声」留下这个位置。正文旁没有弹出的回声按钮。

正文与旁注分别显示来处。星图根据词语的原文位置、最长停留时间、重访次数、文字与空白停留比例、两者之间切换次数、上下滚动折返、当前阅读时长及系统小时变化。星的位置由原文地址确定基础分布，习惯只作缓慢的小幅调整，避免每帧重新随机造成跳动。星图是阅读行为的艺术映射，不判断理解、赞同或阅读完成度。

点击左侧「回声」，可以预览原句；明确点击「回到这句」才改变阅读位置。视听差异在此转化为延迟、积累、余韵、重访的视觉节奏，不播放声音，也不使用模型推断用户的心理。

原句下方的余辉只使用剩余留白，随选中的记录缓缓变化。文字本身保持稳定。静谧或关闭光影后，仍能查看和返回已有记录。

## 记录与返回

每份文稿的停留持续累积，不再裁成最近 24 处。记录按文稿存入本机 IndexedDB；星图只显示有界的视觉摘要，记录列表分批展开，真实记录总数和更早位置仍可访问。可以暂停记录、清除当前文稿的停留，并撤销这次清除。

写入前留下按文稿区分的短期日志，数据库事务提交后再移除；写入失败或立即关闭时，可以恢复最新记录，包括“清空”状态。浏览器本机存储均不可写时，当前打开的记录仍保留在内存中，界面显示“仅本次打开”。旧版本先前已经裁掉且没有其他存档的回声无法凭空恢复。

回声使用主线统一的文字地址。原句预览从当前解析文本取得，先由公共契约核对版本、文字和上下文。缓存保存地址、标题、图谱位置、时间、次数，以及可选的停留与习惯统计，不另存一份展示原文。移开鼠标、滚动或切换主题时结束当前停留；不改变 Markdown。

返回操作等待公共导航确认真正落位。换书、进入载入或编辑、关闭主题或重新打开预览时，旧的等待会取消。无法核对的地址保留词语标识，并停止提供错误的返回位置。

## 版本边界

当前存储为 IndexedDB `zhumo-reading-echo` 的 `books` 对象仓库；旧 v2 Local Storage 在当前文稿没有新存档时迁入。空的新存档仍代表明确的清除，不会从旧 v2 复活。地址继续使用 schema 1、sha256-utf16le-1 和 zhumo-search-text-1。原始 BOM、换行及 UTF-16 码元均遵循主线规则。早期 v1 实验缓存不读取、不改写，也不通过改标签进行迁移。

琉璃与潮光共享同一份回声存档。旧 v2 记录没有统计字段也能正常显示和返回；界面改名为潮光，主题 ID 仍为 `chaosheng`。多窗口合并和跨版本模糊迁移尚不属于当前记录策略。公共契约及实现责任见 [文稿版本与文字地址](text-location-contract.md)。回声视觉与应用图标正在由 Claude Code 重新设计，本文的旧视觉描述不代表用户已认可美术。
