# 全书长卷

打开文稿后，点击左侧「全书长卷」，或目录中的「展开全书长卷」。琉璃把篇章展开为透光的书页，星辰让它们沿轨道排列。可以在空间中先看见文稿的展开，再决定从哪里继续读。

## 浏览与落位

点击邻近书页，或使用下方的左右按钮，右侧会显示所选篇章的原文起首。篇章空间获得焦点后，左右方向键切换，`Home` 到卷首，`End` 到卷末；下方的全书滑杆可以直接移动到更远的篇章。

搜索框查找标题及其上级标题。长书的所有篇章都可查找，结果按页呈现。即使两个标题完全相同，它们也有各自的序号、原文和落位。

浏览期间，正文仍停留在原来的位置。「回到当前阅读处」只把长卷的选择带回打开时所在的篇章；点击「从此处阅读」才进入所选篇章。`Esc` 关闭长卷并返回打开它的按钮。原文较长时，预览只呈现起首，进入正文后继续阅读。

## 旁注与公式

点击预览中的注释标号，或下方列出的旁注，可以展开注释脉络，沿父注和子注继续阅读。关闭脉络后回到刚才的长卷预览；选择脉络中的正文入口或「在旁注中阅读」则进入对应的正文或常驻旁注。

公式可在长卷上方打开细读面板，关闭后焦点返回公式。编号引用与正文标题链接可以直接落到实际文稿中的相应位置。

## 画面如何对应文稿

长卷的篇章来自作者实际写下的一至三级标题。长文内部用于分段渲染的片段会重新接在一起，不会变成额外的章节。无标题文稿作为一份连续正文呈现，首个标题以前的文字保留为卷首。

页边光柱和下方起伏表示正文篇幅。这里统计当前标题之后、下一个一至三级标题之前的正文字符，排除空白、标题和注释标号；公式按原式计入。因此，一个主要容纳下级篇章的标题，本身可能只有很短的正文。右侧「由此展开」可以进入它的直接下级篇章。

书页上方的星点表示直接引用的旁注，最多显示九点；准确数量始终以数字列出。旁注列表只取本段真正出现的引用，共享注释可以从不同篇章进入。轨道表达篇章先后，周围的光影用于营造空间。

「丰沛」启用缓慢变化的光场与鼠标光泽；「静谧」保留静态材质，「关闭」减少光影。系统减少动态效果时，长卷的连续动画和翻页过渡会停止。

可以用[一封信，经过九次阅读](panorama-reading-example.md) 体验篇章、子标题和三级旁注之间的往返。长卷只呈现当前文稿，不会改写源文。
