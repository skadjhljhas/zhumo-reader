# 一句话，在后来改变

“我们会等你。”第一次读到这句话时，我把它理解为一个有关时间的约定。后来才知道，说话的人并不知道我会离开多久。那句话没有增加一个字，我对它承担了什么、没有承担什么的理解，却发生了改变。[^后来]

改变并不只来自迟到的信息。重读旧信时，读者也可能已经经历了当初无法想象的事情。过去的语句因而显出新的重量；但这份重量究竟属于当年的表达，还是属于今天的读者，仍然需要辨认。[^重读]

## 留下来的字

保存原句，使我们有机会看见解释怎样变化。如果每次理解改变以后，都把旧句修订成“我当时其实就是这个意思”，变化便会被藏进一个始终正确的自我叙述。保留旧句不是拒绝修订，而是让修订留下可以回看的位置。

承诺尤其需要这种位置。说话时未知的条件后来出现，可能要求双方重新商议，却不会自动证明原先没有作出过承诺。重新理解一句话，与免除这句话带来的责任，是两个需要分别论证的动作。[^承诺]

## 下一次重读

注释可以记下一次理解发生转折的地方：后来知道了什么，原先忽略了什么，哪些判断仍然没有足够理由。它使读者能够进入解释的过程，也能够从某个分歧处开始自己的讨论。

于是，“我们会等你”可以同时保留那一次说出的痕迹，以及后来没有停止的追问。文本的开放不要求我们放弃判断；它要求判断能够说明自己的来处，并允许后来者检查。[^后来]

[^后来]:
    一句话的字面没有变化，意义的处境却可能变化。“我们会等你”在车站、书信和公共承诺中承担的事情并不相同。把语句从一个处境带到另一个处境时，原来的线索不必全部消失，却也不能假定它们会自动随行。[^痕迹]

    重读的价值，部分在于让先前没有被听见的含义进入讨论。不过，“现在这样读对我很有意义”，并不能单独证明“说话的人当时就是这样想的”。读者的获得与关于作者的断言，需要不同的理由。[^误读]

    因此，保留多种读法并不意味着所有读法获得相同的支持。我们仍然可以检查哪些细节被解释了，哪些细节被略过，以及一条读法遇到不合预期的材料时是否愿意调整自己。[^校准]

[^重读]:
    读者的经历会改变什么首先引起注意。一个曾经只是修辞的停顿，后来可能被读成犹豫；一个当年显得疏远的称呼，后来可能让人察觉其中的克制。

    这些改变可以成为理解的起点，却还不是关于文本的结论。它们需要回到句子、上下文和表达习惯中接受检查。这里与“后来”的讨论相接：新处境能够提出新问题，也需要交代自己凭什么作出回答。[^后来]

[^承诺]:
    一项约定是否仍然有效，要看它原先包含了什么条件，条件是否被改变，以及改变由谁承担。后来发生的困难可能是重新商议的理由；它是否足以解除约定，则是另一个问题。

    把这两个问题拆开，可以避免用意义会变化这一事实，替代对责任的具体判断。“后来”确实改变了理解的处境，但处境变化本身并不预先给出责任的答案。[^后来]

[^痕迹]:
    保留痕迹不等于声称过去可以完整复原。一封保存下来的信仍然可能缺页，一份记录也可能没有写下说话时的语气。材料的留存扩大了可检查的范围，也提醒我们说明范围的边缘。

    因而，“有记录”之后还需要一个问题：这份记录能够支持怎样强的判断？[^证据]

[^误读]:
    如果“误读”仅指偏离唯一正确的答案，我们便需要先说明那份答案怎样确定；如果任何偏离都被称为创造，解释又可能失去回应材料的责任。

    两难之间仍有可做的事：明确这一读法试图回答什么，区分个人联想与历史断言，并让它面对最不容易纳入自己的那一句话。这些动作不保证一次读懂，却使不同读法有了可以相互讨论的部分。

[^校准]: 一种读法如果只能不断增加例外，才能解释眼前的文字，就有理由重新检查它。调整有时发生在结论，有时发生在问题本身：我们原先追问的是作者的意图，后来发现材料只能支持对公开表达的判断。把问题改写得更准确，也是一种理解的进展。

[^证据]: 同一份材料可以支持不同强度的陈述。“这封信写着某句话”与“写信人始终抱有某种态度”相隔很远。后一句需要更多材料，也需要处理与它不一致的表达。这条注释只说明推论跨度的问题，没有为任何现实人物提供历史结论。
