# 多算子阅读：让光显示组合次序

2026-09-08，语言学设计与实现边界。当前渲染已接入基础二维光场与原词层级；下文的类型化量词、限制域和绑定变量仍是拟议协议。语言学核对未调用用户模型。

**核心方案：从“给一个范围画一条光线”升级为“有类型的语义结构 → 分层二维光场 → 常显的紧凑算子次序”。** 光场帮助视线分组，原词与层级确保意义可辨。层层柔光本身不是读者能自动解码的逻辑语言，不能再把可读性寄托在漂亮程度或悬停解释上。

## 2. 一个具体的四算子样例

原句：**并非每位编辑都没有读过至少一篇来稿。**

先声明分析假设：取“至少一篇”在内层否定之内的读法，并暂时只求真值条件核心。`E` 是语境相关编辑，`M` 是相关来稿；`R(x,y)` 表示 x 曾读过 y，保留“过”的经历性，不偷换成“完整读完/完全理解”。

| ID  | 显式线索           | 操作          | 限制域/绑定             | 核心作用对象               | 父环境 |
| --- | ------------------ | ------------- | ----------------------- | -------------------------- | ------ |
| N₀  | 并非               | 命题否定      | 无                      | 整个每位编辑的判断         | 根     |
| Qₓ  | 每位；都为关联线索 | 全称          | `x ∈ E`，限制词为“编辑” | 每位编辑是否处于内层否定中 | N₀     |
| N₁  | 没有               | 否定经历命题  | 无                      | 读过至少一篇来稿           | Qₓ     |
| Qᵧ  | 至少一篇           | 数量下界 `≥1` | `y ∈ M`，限制词为“来稿” | `R(x,y)`                   | N₁     |

组合树是 `N₀(Qₓ(N₁(Qᵧ(R(x,y)))))`。在上述简化下：

```text
A = ¬∀x∈E [ ¬∃y∈M R(x,y) ]
  ⇔ ∃x∈E ∃y∈M R(x,y)
```

它至少承诺有编辑读过来稿；不承诺每位编辑都读过，不承诺有人读过所有来稿。两个否定之间隔着全称量词，不能直接消掉后留下 `∀x∃y`。这里的复杂性是**多个算子的组合**；这段真值核仍能用一阶逻辑表达，不必把它夸称为严格数学意义的高阶逻辑。

“每位”和“都”不能看见两个词就算成两个独立全称算子。“每-NP 是全称、都贡献其他语义/语用条件”是一条有明确论证的分析路线；应用应保留分析依据，不把某一学派的词项拆分当成唯一事实。[Liu，2021，期刊原文](https://link.springer.com/article/10.1007/s10831-021-09227-x)

`≥1` 可以在这个真值核中化为存在量化，**但原始语义节点应仍保存 atLeast/minimum:1**。英文相关实验表明，至少类表达的解释不能仅用数值不等式穷尽，具体语义/语用分工仍有争论；这不能直接证明本汉语句的另一读法，却足以提醒我们不要在数据层擦掉“至少”。[Cummins 与 Katsos，作者稿](https://crcummins.com/Comparative_and_superlative_quantifiers.pdf)

## 3. 歧义必须有语言证据；结构互斥不等于真值互斥

将 Qᵧ 提到 N₁ 之上，会得到另一个数学结构：

```text
B = ¬∀x∈E [ ∃y∈M ¬R(x,y) ]
  ⇔ ∃x∈E ∀y∈M R(x,y)
```

其含义是有编辑读过全部相关来稿。**B 在这里是验证表示能力的对照，不是已证实的同句汉语读法。** 没有足够语境、韵律或构式依据时，不能因为能排列四个算子就向读者自动提供全部排列。针对汉语辖域的实验显示，解释受到构式及说话者差异影响，简单“汉语全刚性/全自由”二选一也不可靠；该实验不是对本句的直接测试。[Wu，2023，原始实验](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2023.1128616/full)

若将来材料确实支持 A/B 竞争，`readings` 同时、完整交付各自的树，一次只在正文投影一棵。这里“互斥”是**展示的结构选择**，不是声称两命题不能同时为真：

| 两位编辑 × 两篇来稿的读过矩阵；1=读过 | A   | B   |
| ------------------------------------- | --- | --- |
| `[[1,0],[0,1]]`，各读不同的一篇       | 真  | 假  |
| `[[1,1],[0,0]]`，一人全读、一人未读   | 真  | 真  |
| `[[0,0],[0,0]]`                       | 假  | 假  |

上表限定两域非空。空域的形式真值要单独保留，不应由光效悄悄补入存在预设。相同真值条件的不同组合路径也不能仅凭树不同就包装成两种不同意思。

## 4. 结构协议：原文、语义树、呈现不能混为一层

建议新增**受约束的类型化语义节点**，不是让模型发送可执行代码或任意公式字符串。示意如下，属于拟议协议，当前解析器尚不支持：

```text
N0: not(body=Qx), cue=“并非”
Qx: forall(variable=x, restrictor=编辑, body=N1), cue=“每位”, associate=“都”
N1: not(body=Qy), cue=“没有”
Qy: atLeast(variable=y, minimum=1, restrictor=来稿, body=P), cue=“至少一篇”
P: predicate(unit=“读过”, arguments={reader:x, theme:y}, aspect=experiential)
```

- **原文锚点层**继续用 quote/occurrence，包括不连续关联线索，不要求模型数 UTF-16 偏移。
- **语义层**区分量词限制域与核心域、绑定变量与谓词角色、真值内容与语用限制。`not` 不绑定变量；量词必须声明限制域、变量和 body；变量引用必须在当前读法中可见。将来事件、世界、命题变量需要显式类型，不能全当人名共指。
- **唯一结构来源**：从语义树导出 `within` 与呈现次序，或验证两者一致；不能让两套树各说各话。旧 `within` 数据仍能显示较粗的关系，但不能靠 label 正则猜出形式逻辑。
- 每个 scope 保留独立 ID、真实父深度、完整祖先路径、原文限制域片段及核心域片段。宽屏与窄屏改变布局，不压扁语义树；不能用 `Math.min(3, depth)` 把第五层当成第四层。
- 四算子的最小自足批次一次交付；后续可补语用信息。候选分叉需要原子提交，显影中途不能短暂显示另一种极性。未决次序可以先显示原词的算子身份，**不虚构嵌套光场**。

## 5. 光学方案：二维薄光、局部映射、留白中的次序

主要视觉不再是一串上下划线。做一个由语义树驱动的 `ScopeField`，在文字背后产生二维、边缘渐隐的薄光；文字颜色、笔画和不透明度保持稳定，任何否定都只作用于光层，绝不把正文抹淡。

**三个同时可见的通道承担不同信息：**

1. **算子原词是光源的锚。** N₀/N₁ 都用否定家族，但各有稳定身份；Qₓ/Qᵧ 都属量化，却必须分出“遍及域”和“下界满足”。“每位”附近是向范围展开的细密平行光纹；“至少一篇”附近是由稀到密、仍向外开放的阈值光纹；否定是薄光中柔和的相位折返/亮暗界面。它们是编码，不画编辑、来稿、小球或实体图标，纹条数量也不假装等于人数。
2. **核心域是一片薄光，限制域另有精确落点。** 依据 DOM 实际行片段生成宽而柔的渐变面，覆盖字间与行间，局部峰值避开笔画区域；不要把整个段落的 bounding box 涂色。算子到限制词采用相同身份的局部光纹，避免“至少一篇”看上去在量化编辑。跨行利用现有空白测量和 27 通道保留连续性，遇到图片/公式留出实测空隙。
3. **句旁保留极轻的常显次序谱。** 在真实空白中排列原词 `并非 › 每位 › 没有 › 至少一篇`，用缩进/分叉表达内外；同句各算子与此处保持相同身份。它是少量可读文字与渐隐薄光，没有卡片、边框或悬停标签。空间不足时在句后占用一行轻排版，也不把四层强挤成无法辨认的三条线。数学熟悉者可切换 `¬ › ∀ › ¬ › ≥1`，默认显示原词。

这里的次序不能依赖动画、颜色名称或随机相位才能认出。把时间冻结、改为灰度，仍需能沿层级认出 N₀→Qₓ→N₁→Qᵧ。静态几何、原词与身份对应承担信息，缓慢折射仅增添气息。

**层叠必须有顺序，不能只是把四种光相加。** 简单加法满足交换律，交换内外算子后仍可能长得一样。实现上按树嵌套独立 mask/group，父环境限定子场的开口、边界与出入口，邻接/包含关系以拓扑保持；不同父子次序必须生成不同场结构与不同次序谱。其光场是组合结构的编码，不能冒充对真值的物理计算。

每个身份由当前文段内的稳定 operator ID 生成；同色家族使用位置、光纹方向、原词对应冗余区分。时间、随机美学变化不能重排身份或改变范围。降低动效时保留完整结构，关闭光效时原文仍完全正常。

## 6. 本次已经验证什么

- 使用当前真实 `parseSyntaxGraph`、`syntaxProjection`、`syntaxOpticalPlan` 在纯 Node 内存中检查：本句 **10 个单位、11 个锚点、4 条 scope** 合法；现有引擎输出的家族/level 为 `negation:3 → quantifier:2 → negation:1 → quantifier:0`。证明已有图协议能装下父子链，也证明仅通过协议并不等于已区分量词种类与语义域。没有写入脚本或改动源码。
- 枚举编辑/来稿域大小各为 0–3 的全部 **689 个有限模型**，核对上面的 A、B 各自与右侧公式等价，失败 **0**；反例矩阵明确区分 A/B。这是形式核心的核对，不是验证汉语可接受性，更没有评测或调用用户模型。
- 基础二维光场和原词层级已实现；量词子类、阈值等专用光纹仍属于方案，不能声称全部通过真实阅读验收。四算子、灰度和排版检查是绘制证据，后续仍需在深层嵌套和有依据的分支句中让人直接指出“谁管谁”“量化什么”“换序后意思怎样变”。这才是检验新光效是否真正辅助阅读的标准。
