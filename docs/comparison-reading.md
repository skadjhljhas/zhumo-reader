# 让两处原文相遇

按 Ctrl+F 找到一句话，在右侧点「留作左页」。再选择另一处结果，或换一个词检索，点击「并置阅读」。同一段中两次出现的词也能分别选择；每页保留自己的标记与出处。

两页分别滚动，原来的强调、列表、表格、公式、图解和注号继续存在。点注号可以逐层展开注释脉络；点击公式或图解，仍能放大、查看源文，再回到这一页。顶部可交换左右；关闭对读返回原来的检索。

页边细线连接当前可见的两处标记。它不表示语义相似度、因果或推理结果。标记滚出视野，连线便隐去；点该页「回到标记」可以重新找到它。

## 长段与来处

长段以约六千个字符为一片，前后片保留重叠；公式与图解作为完整对象呈现，可能使一片更长。用「往前读」「往后读」翻到本段其他部分。左右两页各有进度，滚动一页不会推动另一页。

「复制此段」复制完整段落的文字，包含未展开的部分；「复制两段及出处」同时带上两页标题与正文／旁注来源。复制不修改文件。点击各页「回到原文」，才离开对读并定位原来那一次字句。

左页在同一份文稿的检索中临时保留，也可以清除。打开其他文稿、保存使原文更新，旧选择会清空，避免拿同名词冒充原来的位置。对读不保存成独立书签，也不跨版本猜测迁移。

如果正在编辑，进入对读会沿用保存、放弃或继续编辑的现有选择。保存后原文已变化时，需要从新结果重新选择两页。阅读模式下浏览、选字和复制始终保持阅读。
