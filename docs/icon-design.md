## 构图

图标里只有一个实体：一枚小小的朱红印章，位于画面上三分之一处。它下方是这枚印在墨色海面上的倒影，一道从暖金过渡到月白、向下渐渐消散的光柱，微微摇曳，途中有两三道被长浪切开的碎光。底是从墨蓝到沧海蓝的深色圆角方块，右上角有一点像月光的空气感，边缘一圈极淡的亮边帮助它在深色任务栏上保持轮廓。

它字面上就是"朱墨"：朱是那枚印，墨是那片海。它同时也是这个阅读器的美学：唯一实的东西很小，其余都是光。光柱既像月光在水面拉出的光路，也像一枚书签，不需要画一本书。

## 小尺寸

Windows 任务栏与资源管理器实际使用 16/20/24/32 像素。这些尺寸使用 `resources/icon-small.svg`：同样的印与光柱，但印章放大到约四分之一边长，光柱改为直线、无碎光、模糊减少，亮边加粗。`scripts/build-icons.mjs` 在 32 像素及以下自动切换到这份源稿；40 像素起使用完整源稿。两份源稿的配色一致，缩放时不会跳色。

## 生成

矢量源：`resources/icon.svg`（完整）、`resources/icon-small.svg`（小尺寸）。命令 `npm.cmd run build:icons` 在隐藏的无头 Edge 中栅格化，生成 `resources/icon.png`、`build/icon.png`、`build/icon.ico`（16、20、24、32、40、48、64、128、256）与 `build/icon.icns`（16 到 1024），并把 11 个尺寸的预览写到 `work/icon/`。
