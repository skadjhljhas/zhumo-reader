# 新建文稿、主题 PDF 与 EPUB

## 新建 Markdown

欢迎页、阅读工具栏和 Ctrl+N 都可以新建 Markdown，立即进入源文编辑器。首次保存使用既有的默认文稿目录与另存流程，生成 .md 文件；新建时不要求先命名文件。现有文稿仍有未保存修改时沿用保存/放弃保护。

未保存的新文稿使用独立临时书籍编号，恢复草稿写入用户资料中的 IndexedDB。重新启动后，欢迎页列出这些新文稿，可以继续编辑。保存与恢复不会覆盖别的窗口保留的不同草稿。

## 主题 PDF

工具栏的「导出 PDF」默认保留当前阅读主题；支持 A4 纵向/横向，以及是否包含全部注释。全文从完整解析结果生成，不依赖当前屏幕上挂载了哪些章节。使用中的字体会传给独立导出页面，已有双颜色标注以静态字色和渐变荧光呈现，不额外请求模型。琉璃/星辰/潮光的背景与标题光场定格。

正文与短注释并置；相对正文过长的注释获得全文宽度。公式、表格按纸张可用宽度适配，图表重新用当前主题生成，矢量图与公式保持可放大。页面包含页码和文档目录；不把实验性的 PDF 标签功能称为完整 PDF/UA 认证。主题 PDF 是静态输出，不宣称保留屏幕 HDR 的实际亮度。

导出在不显示、不获取焦点、无 Node 接口且禁止页面脚本的独立窗口中完成；使用独立非持久会话。原文不会被修改。目标 PDF 在导出期间被其他程序改动时停止覆盖。临时目录仅由本次导出创建，并在核对范围后清理。

## EPUB 阅读

支持常见未加密 EPUB 2/3 流式书籍：按 OPF spine 读取章节，支持 EPUB 3 导航与 EPUB 2 NCX、插图、Ruby、MathML、书内链接、脚注与多处引用。内容融入朱墨的主题、字体和阅读空间。章节与注释建立独立的文本定位信息，供解释与自动文字光效取得正确语境。

原 EPUB 以阅读模式打开；普通文本保存接口不接受 .epub，避免把电子书容器改写成文本。压缩内容只在内存读取，不按压缩包路径解压到用户文件夹。存在资源/读取上限；脚本、作者样式和交互式页面控件不执行。固定版式、音视频和 DRM 不在当前阅读能力声明之内。

可通过打开文件、拖放、最近阅读或启动参数打开 EPUB，也可导出为 PDF。原电子书的字节保持不变。

## 验证

`tests/main/epub.test.ts` 使用原创 EPUB 2/3 夹具验证顺序、目录、图像、资源定位和加密/损坏输入拒绝；`reading-source.test.ts` 校验导入文本的精确位置及错误偏移拒绝。

`tests/e2e/documents.spec.ts` 检查新建/首次保存/重启恢复、EPUB 导航/图片/共享脚注/脚本隔离、实际全文语境的本地固定流式标注，以及主题 PDF 的已有标注和自选字体。`pdf-layout.spec.ts` 检查潮光与纸面、长注、表格、宽公式和图表，导出页面不得产生横向溢出。

PDF 文件另以文本提取与逐页 PNG 检查内容、分页、对比度和裁切。文本提取对中文两端对齐可能插入空格，内容核对会规范化这些空格，不能仅凭生成成功或 PDF 头标记宣称版式正确。
